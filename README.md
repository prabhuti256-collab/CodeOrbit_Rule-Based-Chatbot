
# 🤖 PyBot - AI Chatbot

## About the Project
PyBot is a simple rule-based chatbot developed using Python
and Streamlit. It responds to user messages using predefined
keywords and rules.

This project was developed as part of an Artificial
Intelligence internship project.

## Features
- Interactive web-based chat interface
- Greeting detection
- Answers questions about Artificial Intelligence
- Information about Python and Machine Learning
- Deep Learning and Streamlit explanations
- Conversation history
- Clear Chat functionality

## Technologies Used
- Python
- Streamlit

## Installation

1. Clone or download this repository.
2. Open the project folder in a terminal.
3. Install the required dependency:

   pip install -r requirements.txt

4. Start the application:

   python -m streamlit run app.py

5. Open the local URL displayed in the terminal.

## How It Works
1. The user enters a message.
2. The chatbot checks the message against predefined rules.
3. A matching response is returned.
4. The response appears in the Streamlit chat interface.
